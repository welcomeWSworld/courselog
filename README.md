# CourseLog — 산책·러닝 코스 기록 웹앱 (MVP)

GPS로 걷기/뛰기 코스를 기록하고, 지도에 표시하고, 공유하는 웹앱입니다.
빌드 과정이 없는 정적 파일(HTML/CSS/JS)이라 어디에 올려도 바로 동작합니다. 서버·DB·API 키가 없어 무료입니다.

## 기능
- 걷기/뛰기 선택 → 시작 → 일시정지/재개 → 종료
- 실시간 시간·거리·평균 페이스, GPS 정확도 표시
- GPS 튐 보정: 오차 35m 초과 위치 무시, 3m 미만 흔들림 무시, 비정상 속도 무시
- 화면 꺼짐 방지(Wake Lock, iOS 16.4+)
- 기록 중 앱이 닫혀도 다시 열면 이어하기
- 기록은 이 기기 브라우저(localStorage)에 저장
- 공유
  - **링크**: 코스 전체가 링크 안에 들어 있어서 서버 없이 다른 사람이 열어볼 수 있음
  - **이미지**: 인스타 비율(1080×1350) 코스 카드 → iPhone 공유 시트로 사진 저장/전송
  - **GPX**: Strava·Garmin 등에 가져갈 수 있는 표준 파일

## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성 |
| `style.css` | 스타일 (다크 모드 지원) |
| `geo.js` | 거리 계산, 경로 단순화, 링크 인코딩, GPX 생성 |
| `app.js` | 지도, GPS 기록, 저장, 공유 |

## PC에서 테스트 (가짜 GPS)
```
python -m http.server 5173
```
브라우저에서 `http://localhost:5173/?sim=8` 을 열면 가짜 GPS가 8배속으로 움직입니다.

## iPhone에서 테스트
iPhone Safari는 **https 주소에서만** GPS를 허용합니다. 아래 중 하나로 무료로 올리면 됩니다.

1. **Netlify Drop** — https://app.netlify.com/drop 에 `courselog` 폴더를 끌어다 놓기 → https 주소 생성
2. **GitHub Pages** — 저장소에 올리고 Settings → Pages 에서 활성화
3. **Vercel / Cloudflare Pages** — 정적 사이트로 배포

iPhone에서 열고 공유 버튼 → "홈 화면에 추가" 하면 앱처럼 쓸 수 있습니다.

## 알려진 제약
- 웹앱은 화면이 꺼지거나 다른 앱으로 전환하면 iOS가 GPS를 멈출 수 있습니다. 기록 중엔 화면을 켜두세요. 끊긴 구간은 직선으로 이어집니다.
- 기록은 기기 브라우저에만 저장됩니다. Safari 데이터 삭제 시 함께 지워집니다.
- 지도 타일은 OpenStreetMap 공개 서버를 씁니다. 테스트 용도엔 충분하지만 사용자가 많아지면 별도 타일 서비스가 필요합니다.
